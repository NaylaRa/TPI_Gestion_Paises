#  TPI – Gestión de Países en Python

##  Descripción del proyecto
Este proyecto fue desarrollado como Trabajo Práctico Integrador para la materia **Programación 1**, de la **Tecnicatura Universitaria en Programación (UTN)**.  
El objetivo es construir una aplicación en **Python** que permita gestionar información sobre distintos países, aplicando listas, diccionarios, funciones, estructuras condicionales, filtros, ordenamientos y estadísticas básicas.

---

##  Funcionalidades principales
- Agregar y actualizar datos de países.  
- Buscar por nombre (exacto o parcial).  
- Filtrar por continente, población o superficie.  
- Ordenar por nombre, población o superficie.  
- Calcular estadísticas básicas (máximos, mínimos, promedios, conteo).  
- Guardar los cambios en un archivo CSV.
